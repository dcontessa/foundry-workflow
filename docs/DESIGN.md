# Design system

Reference: public/design/concept.png, generated full workbench concept at 1536 x 1024.

Autonomous design choice within the approved product plan: warm off-white #f5f3ed, charcoal #242722, copper #a34b2c, gray #d7d6ce dividers. Serif display headings, DM Sans controls with system fallbacks. Flat three-column workbench, restrained 3px corner radii, no hero imagery or overlays.

Primary components: app header, brief and rules rail, enquiry table, evidence rail, version comparison, enquiry form dialog. Desktop columns collapse into a two-column board with full-width evidence below, then a mobile vertical sequence. A horizontally scrollable table preserves readable fields on mobile.

Allowed primary copy: Foundry; Describe; Workbench; Prove; Sample mode; Make it work. Then prove it.; Turn a messy process into a workflow you can test.; Problem brief; Interactive enquiry board; Test and gather evidence; Synthetic demo data; Build workflow; Run tests; Compare results.

Intentional changes from generated concept: use the five approved executable scenario names instead of the image's invented response and audit tests; replace generic rule list with actual engine booleans; compare actual test pass counts instead of unsupported business metrics; use Propose repair before Apply repair & rerun; add an Add enquiry form and evidence download for the authorized workflow; responsive layouts and clear sample disclosures. Plain Foundry text branding with copper punctuation is code-native.
